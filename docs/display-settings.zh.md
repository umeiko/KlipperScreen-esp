# 显示与编码器设置

从 **v0.5.8** 起，在 **设置 → 显示设置** 中提供。选项按固件的输入/显示能力出现，
普通 Windows/macOS 桌面程序不展示这些硬件调节项。

## 编码器步进：1 / 2 / 4

这个数字表示**每个机械卡位产生的正交计数**，不是每圈格数，也不是编码器型号。
仅编译启用了旋转编码器的 ESP32 固件展示此项。

- 转两格才走一项：尝试减小数值，例如 **4 → 2**。
- 转一格跳过多项：尝试增大数值。
- 菜单只有 **1、2、4**，当前值直接显示数字；首次修改前沿用板型的编译默认值。

选择后进入 **20 秒试用**。转动编码器，检查是否每格走一项，明确按“确认”后才保存。
弹窗默认聚焦“恢复”；按恢复、返回、超时或离开页面都会恢复原值。
未确认就重启也不会保留试用值，避免选错后无法操作。

此设置不能修复接触抖动、接线错误或丢脉冲等硬件问题。

## 屏幕色序：默认 / RGB / BGR

点击“屏幕色序”进入下一级页面，直接在 **默认、RGB、BGR** 三行列表中选择。
移动焦点不会修改，按下才应用；当前项带标记。选择即时生效并保存，重启后仍保留。
色序选错不影响导航，可以直接切回来，因此不需要步进设置那样的倒计时确认。

观察下方标有 **红、绿、蓝** 的三个色块，文字随界面语言切换。
如果红蓝互换，尝试另一种色序，绿色应保持不变。
“默认”恢复板型原来的色序，**并不一定等于 RGB**。

色序与反色、RGB565 高低字节顺序是不同概念。旋转或水平镜像不会把已选色序改回去。
不是所有颜色异常都能通过此项修复。

已接入 ST7735S、ST7789、ILI9341、ST7796、ILI9488 的 SPI LCD 后端，
包括立创实战派 JLC-SZP 的自定义 SPI 路径。JC8048W550 的 RGB 并口屏保持原稳定路径，
不展示此项。具体板型见[支持的板子](boards.md)。

## 验证边界

Windows 交互已在发版前验收，自动检查覆盖试用/恢复、配置保存、翻译、RGB/BGR 行为和
MADCTL 方向位保持。构建只能证明软件集成，不代表所有实体屏幕都已实测。
刷机后请在自己的模组上检查三色块和显示方向。
